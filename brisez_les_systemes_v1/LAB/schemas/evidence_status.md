# États de preuve

- `NON_EXECUTE` : outil ou données non lancés.
- `MODEL_PREDICTION_NOT_EMPIRICAL` : prédiction Maia-3, à ne pas présenter comme une fréquence réelle.
- `DISCOVERY_ONLY` : résultat trouvé sur l'échantillon de découverte.
- `VALIDATED` : reproduit sur l'échantillon de validation.
- `TEST_CONFIRMED` : reproduit sur un échantillon temporel tenu à l'écart.
- `EXTERNAL_REVIEWED` : ligne vérifiée par un entraîneur/joueur fort.
- `PUBLISHABLE` : toutes les portes de publication sont franchies.
