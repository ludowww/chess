# Charte éditoriale V1

## Unité d’apprentissage

Une leçon doit enseigner une décision, pas réciter une branche. Elle contient :

- un déclencheur visuel ;
- une croyance humaine exploitée ;
- un coup-clé ;
- une justification concrète ;
- un plan simple pour les Noirs ;
- une ligne de sécurité si l’adversaire répond correctement ;
- une phrase mémoire ;
- un statut de preuve.

## Ce qui est interdit

- présenter une prédiction Maia comme une statistique réelle ;
- utiliser “gagnant” pour une position seulement égale mais inconfortable ;
- recommander un sacrifice dont la compensation dépend d’une suite machine impraticable ;
- conserver une variante uniquement parce qu’elle est spectaculaire ;
- noyer une idée sous des alternatives sans incidence pédagogique ;
- copier les annotations, le plan ou la formulation d’un cours tiers.

## Hiérarchie des contenus

- **Cœur durable** : sain, enseignable, robuste à plusieurs Elo et contre la meilleure défense.
- **Arme de club** : très efficace dans une plage Elo, mais déclin clair au-dessus.
- **Bonus tactique** : piège sain, court et honnêtement présenté.
- **Bibliothèque** : ligne plausible qui n’a pas encore gagné sa place.
- **Rejet** : ligne douteuse, trop précise pour nous, trop rare ou redondante.

## Règle de densité

Le parcours central est limité à 40 idées. Une nouvelle idée ne s’ajoute pas : elle doit remplacer une idée moins utile. La bibliothèque peut croître, pas le cœur du cours.
