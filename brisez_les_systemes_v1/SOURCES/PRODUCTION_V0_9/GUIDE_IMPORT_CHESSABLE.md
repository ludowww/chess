# Guide d’import Chessable

1. Créer un cours privé et ses chapitres dans le même ordre que les fichiers PGN.
2. Importer un fichier PGN par chapitre ; chaque partie PGN correspond à une ligne entraînable.
3. Vérifier que le côté entraîné est **Noir**.
4. Conserver les commentaires de position-clé ; raccourcir seulement les commentaires de fin si l’interface les juge trop longs.
5. Marquer les lignes “Essentiel” comme prioritaires et les lignes “Avancé” comme variations secondaires.
6. Tester le MoveTrainer sur mobile et ordinateur : ordre des coups, transpositions, répétitions inutiles et variantes dupliquées.
7. Ne pas fusionner toutes les parties en une seule arborescence avant le bêta-test : les unités courtes facilitent l’identification des erreurs éditoriales.
8. Après bêta, construire une table des matières visible avec la promesse de chaque chapitre, pas seulement le nom de l’ouverture.
