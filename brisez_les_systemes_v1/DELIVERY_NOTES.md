# Notes de livraison — V1.0.0 RC1

## Réalisé

- sélection éditoriale de 40 idées parmi 88 lignes ;
- huit familles d’erreurs humaines, cinq idées chacune ;
- parcours essentiel de 20 lignes ;
- manuscrit détaillé et cartes mémoire réécrits ;
- manifestes FEN/coup-clé pour Stockfish, Maia-3 et Lichess ;
- scripts reproductibles d’audit, de prédiction, d’extraction et de scoring ;
- règle technique empêchant un score composite si une couche de preuve manque ;
- neuf tests automatiques réussis ;
- bibliothèque V0.9 conservée séparément.

## Non exécuté dans cet environnement

- Stockfish V1 : aucun binaire Stockfish présent localement ;
- Maia-3 : l’installation a été tentée, mais l’environnement de construction ne pouvait pas résoudre `github.com` ;
- Lichess : aucun export mensuel téléchargé ;
- relecture titrée, bêta-test et import Chessable final.

## Conséquence

La V1 est un cours complet en contenu et un laboratoire exécutable, mais reste une release candidate. Les colonnes empiriques sont volontairement vides et les 40 scorecards portent le statut `INSUFFICIENT_EVIDENCE` jusqu’à exécution du pipeline.
